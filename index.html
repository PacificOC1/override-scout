Points calculation

RawScore = (R1_G1 + R1_G2 + R2_G1 + R2_G2) × 5 AutoBonus = +12 pts to higher-scoring alliance (SC7) +6 to each alliance if tied on raw score FinalScore = RawScore + AutoBonus

Win probability (16-outcome model)

Each robot independently succeeds or fails each match. All 16 combinations (2⁴) are enumerated. For each outcome: P(outcome) = ∏ P(robot_i succeeds or fails) P(succeed) = 1 − FailRate P(fail) = FailRate Scores are computed per outcome, then the bar segments are sized proportionally to P(outcome). Red win % = Σ P(outcomes where redScore > blueScore) Blue win % = Σ P(outcomes where blueScore > redScore) Tie % = Σ P(outcomes where scores are equal)

Win probability (distribution-aware model) NEW

Extension of the 16-outcome model that uses each robot's Fail Pin Distribution instead of a single fail outcome. On success: robot scores its entered G1 + G2 pins. On fail: robot scores according to its Fail Pin Distribution (empirical discrete distribution, see below). All outcome combinations are enumerated (cartesian product). Each branch has weight = P(succeed) or P(fail) × weight(pins). For each outcome: P(outcome) = ∏ P(robot_i branch) P(succeed) = 1 − FailRate P(fail, k pins) = FailRate × dist_weight(k) [normalised to sum=1] Scores are computed per outcome, then bar segments are sized proportionally to P(outcome). Red win % = Σ P(outcomes where redScore > blueScore) Blue win % = Σ P(outcomes where blueScore > redScore) Tie % = Σ P(outcomes where scores are equal)

Fail pin distribution NEW

When a robot fails, it may still score partial pins. The Fail Pin Distribution models this as a discrete empirical distribution entered manually per robot. Input: % weight for each pin count (0 pins, 1 pin, 2 pins, …) Weights are normalised so they sum to 100%. Example: 0 pins → 60%, 1 pin → 30%, 2 pins → 10% → P(fail, 0 pins) = 0.60 × FailRate → P(fail, 1 pin) = 0.30 × FailRate → P(fail, 2 pins) = 0.10 × FailRate If no distribution is entered, fail defaults to 0 pins (100%). Each pin count becomes a separate branch in the outcome tree.

AWP probability

AWP is a deterministic rule, not a per-robot probability. An alliance earns the Autonomous Win Point if: 1. Total alliance pins scored ≥ 7 2. At least 3 goals have ≥ 2 pins each For each outcome scenario the calculator checks whether the alliance's combined pin counts satisfy both conditions. The AWP % in the legend is the sum of probabilities of all scenarios where the rule is met. AWP earns WP (ranking pts), NOT autonomous match score.

TrueSkill win probability NEW

P(A beats B) = Φ( (μA − μB) / √(2β² + σA² + σB²) ) β = 25/6 ≈ 4.167 (standard TrueSkill β) μ = skill mean, σ = uncertainty (standard deviation) Φ(x) = standard normal CDF (Abramowitz & Stegun approx.) — implemented as normalCDF(x), max error < 1.5 × 10⁻⁷ Alliance σ is pooled: σ_alliance = √((σ₁² + σ₂²) / 2) Source: Microsoft TrueSkill (Herbrich et al., 2006) Data: vrc-data-analysis.com — VRC Worlds 2026 (1,362 teams)

Worked example

Red: R1 → 4 pins total, 0% fail | R2 → 3 pins total, 0% fail RawScore = 7 × 5 = 35 Blue: R1 → 5 pins total, 0% fail | R2 → 5 pins total, 0% fail RawScore = 10 × 5 = 50 Blue wins raw (50 > 35) → Blue gets +12 auto bonus Final: Red 35 pts, Blue 62 pts With 0% fail rates → P(both succeed) = 100% → Blue wins probability = 100% in this outcome

RFORCE-style rankings

Local scouting approximation of the RFORCE Index formula. Not official — no judge awards or full RobotEvents ranking data. Per event, three per-team rank points are computed: RANK_EP(rank, total) = ((1 + total − rank) / total) × 10 EP = Avg Pins RANK + AWP Rate RANK + Success Rate RANK Event caliber (avg pins across all teams at that event): RFER = 1 + log₁₀(EventCaliber + 1) × EventLevel × EventBonus EventLevel: Local=1.0 · Sig/Regional=1.25 · National=1.5 · World=2.0 EventBonus = 1 + (n² − 1) / max(1, N²) where n = events this team attended, N = max events by any team EventScore = EP × RFER RFORCE = Σ(EventScores) ÷ events attended Combined score = 60% × normalised(RFORCE) + 40% × normalised(TrueSkill)

OPR · DPR · CCWM (Test Rankings)

Computed from scouted match entries; each entry = one robot in one match. OPR (Offensive Power Rating) = avg pins scored per entry Measures raw offensive output per appearance. DPR (Defensive Power Rating) = avg of max(0, EventAvg − pins_scored) per entry Represents how much below the event average a team performs — a proxy for how much defensive pressure opponents imposed. Lower DPR = better relative performance under pressure. CCWM (Calculated Contribution to Winning Margin) = OPR − DPR Net contribution: positive = adds more than it concedes. EventAvg = mean pins across all entries at that event.

OpenSkill — Weng-Lin Bradley-Terry Full

Source: Weng & Lin, JMLR 2011 §3.1 — same model as openskill.js v4. Parameters (openskill.js defaults): μ₀ = 25 (initial mean) σ₀ = 25/3 (initial uncertainty ≈ 8.333) β = 25/6 (performance noise ≈ 4.167) τ = 25/300 (dynamic factor ≈ 0.0833) κ = 0.0001 (σ floor multiplier) Each scouted entry = 1-v-1 vs a fixed "field" opponent (μ=25, σ=σ₀/2). Win condition: team pins ≥ event average for that entry. Update equations (Bradley-Terry Full, §3.1): c = √(σᵢ² + σq² + 2β²) p_iq = Φ((μᵢ − μq) / c) — win probability s = 1 (win) or 0 (loss) Ω = (σᵢ²/c) × (s − p_iq) — mean update Δ = (σᵢ²/c²) × p_iq × (1−p_iq) — variance update μᵢ' = μᵢ + Ω σᵢ' = √( max(σᵢ²(1−Δ) + τ², (κσ₀)²) ) Φ(x) = standard normal CDF (Abramowitz & Stegun polynomial, max error < 1.5×10⁻⁷) Ordinal = μ − 3σ (99.7% lower bound — conservative display rating) Entries processed in chronological order (created_at ascending).

About us

We're Team 97230F — Bot Go Brrr — a VEX V5 Robotics team from Highvale Secondary College in Melbourne's south-eastern suburbs, competing in the 2026–27 Override season.

This scouting database was built entirely by our team to track autonomous performance across events — pin counts, AWP rates, robot types, route notation, TrueSkill ratings — and to sharpen our alliance selection at Signature qualifiers and beyond.

All data is updated live throughout the season by our scouting team. The app is free and open to any team that finds it useful.

🏆 We're going to Worlds!

We qualified to represent Australia at the VEX World Championship in St Louis, USA. As a public school team we rely on community support to cover the costs of getting there.
